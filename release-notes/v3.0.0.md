# AmbiCrew v3.0.0 Release Notes

基于 cc-haha v0.2.6 ~ v0.3.1 的优化和修复，移植适用于 AmbiCrew 的改进项。

---

## 性能优化

### 长会话渲染性能提升

- **React.memo 应用于 6 个重渲染组件** — `UserMessage`、`AssistantMessage`、`ThinkingBlock`、`ToolCallBlock`、`ToolResultBlock`、`ToolCallGroup` 全部包裹 `memo()`，避免父组件状态变化时不必要的子组件重渲染，500+ 消息会话滚动流畅度显著提升
- **Markdown 渲染缓存优化** — 实现 FNV-1a hash 的 module-level LRU 缓存（200 条 finalized + 4 条 streaming），组件卸载/重挂载时无需重复解析；`MarkdownRenderer` 自身也包裹 `memo()`
- **toolResult 查找已为 O(1)** — 确认 `buildRenderModel` 返回 `Map<string, ToolResult>` 并被 `useMemo` 包裹

## 新功能

### 会话分支（Session Branching）

在对话中的任意用户消息处创建非破坏性分支，源会话完全不受影响。

- **后端**：新增 `POST /api/sessions/:id/branch` API，读取源 JSONL 到目标消息处写入新文件，附加 `branchOrigin` 元数据追踪分支来源
- **前端**：用户消息 hover 时显示 "Branch" 按钮（`call_split` 图标），点击后自动创建分支会话并在新 tab 中打开
- 分支包含目标 turn 的完整回复（用户消息 + 所有后续 assistant/tool 消息直到下一个用户消息）
- 适用场景：探索多种方案、保留历史对话的同时尝试新方向

### Memory 项目树面板

将记忆管理从扁平列表升级为按项目组织的树形资源面板。

- **后端**：新增 `GET /api/memory` 和 `GET /api/memory/file` API，自动扫描 `~/.claude/projects/*/memory/` 下所有 `.md` 文件，解析 frontmatter 提取描述和类型
- **前端**：Settings 新增 "Memories" tab，包含：
  - 按项目分组的可折叠树形列表
  - 实时搜索（按名称和描述过滤）
  - 每条记忆显示类型图标（user/feedback/project/reference）
  - 点击后右侧显示 Markdown 预览（支持数学公式）
  - 最近修改的项目排在前面

### 侧边栏按项目分组

- 新增分组模式切换按钮（时间 / 项目），偏好持久化到 localStorage
- 项目分组模式下，会话按项目根目录名称归类，最近活跃的项目排在前面
- 时间分组保持原有行为（今天、昨天、7天内、30天内、更早）

### LaTeX 数学公式渲染

- 集成 KaTeX 库，支持 `$...$` 行内公式和 `$$...$$` 块级公式
- 自动跳过货币金额（如 `$5.00`）避免误渲染
- DOMPurify 配置允许 MathML 标签，确保公式 HTML 不被清理
- 内容预检测：仅在包含数学表达式时才执行 KaTeX 渲染，零开销对普通文本

## 交互体验增强

### Streaming Tool Preview

- 工具执行时显示 pending tool card（替代原有的通用 "Running..." 指示器）
- 显示工具名称、对应图标、文件路径或命令预览
- 对 Write/Edit 工具显示多行内容预览（最多 6 行）
- 对 Bash 显示命令、对 Agent 显示描述

### AskUserQuestion 多行编辑器

- 自定义回答输入从单行 `<input>` 升级为多行 `<textarea>`
- 支持 Ctrl/Cmd+Enter 提交（Enter 键用于换行）
- 可调整高度（min 72px, max 200px）
- 底部提示快捷键

### Tab 切换草稿保护

- 切换 tab 时自动保存当前输入和附件到 per-session draft map
- 切回时自动恢复，不再丢失未发送的内容
- 解决了草稿在多 tab 间泄漏的问题

### Compact 可视化

- Context compaction 事件在聊天时间线中显示为带分隔线的信息卡片
- 显示压缩图标、消息内容、移除的消息数、token 变化（如 "125k → 45k tokens"）
- 替代原有的纯文本 "Context compacted" 系统消息

### "跳转到最新" 浮动按钮

- 当用户向上滚动超过底部阈值且消息数 > 10 时，显示浮动按钮
- 点击后平滑滚动到最新消息并恢复自动滚动
- 滚动回底部时自动隐藏

### 长 URL 不撑破消息气泡

- Markdown prose classes 添加 `prose-a:break-all`，长链接在气泡边界处自动换行

## Windows / Electron 稳定性

### Windows 跨驱动器文件系统访问

- 文件系统 API 允许访问任意本地驱动器路径（`C:\`、`D:\` 等），不再限制为用户主目录
- 修复驱动器根路径规范化：`C:` → `C:\`，避免路径比较时的混淆

### 文件搜索 Git-First 方案

- 文件搜索优先使用 `git ls-files --cached --others --exclude-standard`
- 自动尊重 `.gitignore`，天然过滤 `node_modules`、`dist`、`build` 等目录
- 非 git 目录回退到递归 walk（保留原有 IGNORED_DIRS 过滤）
- 搜索结果同时包含匹配的文件和目录
