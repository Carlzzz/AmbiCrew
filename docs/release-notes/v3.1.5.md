# AmbiCrew v3.1.5

发布日期：2026-06-29

本次发布以**修复 + 上游同步**为主，没有破坏性改动。重点修了三类问题：CLI 子进程在停止 / 重连场景下产生的误报、Windows 平台 cwd / 路径校验细节、以及"新会话首条消息覆盖手动标题"的体验缺陷。

---

## 🐛 Bug Fixes

- **停止流时不再弹 "Stream ended without receiving any events" 错误条**。`translateCliMessage` 在 assistant 分支早期补加 `sessionStopRequested` 守卫，与 result 分支对称。
- **AskUserQuestion 在 CLI 重放时不再出现重复弹窗 / 卡片**。`chatStore` 对 `tool_use_complete` 按 `toolUseId` 做幂等去重，覆盖 server 端只对 `control_request` 去重留下的缺口。
- **新会话首条消息不再覆盖用户的手动重命名**。`wipeSession` 写初始 entries 前显式保留 `custom-title` 行，placeholder 替换不再吃掉重命名。
- **Skill 安装在 Windows Defender 实时扫描下不再 500**。PowerShell `Expand-Archive` 改 `execFile`（非阻塞）+ 90s 上限，超时返回 504。
- **ContextUsageIndicator 在大会话下不再频繁记 `client_api_request_failed`**。客户端超时从 20s 提到 24s，避开 server 端 20s tokenize 边界。
- **CLI 子进程 `[tools:` / `[claude:` / `[print:` 前缀的 stderr 不再被记成 runtime error**。

## 🪟 Windows 平台

- **bypass 模式允许映射盘工作目录**（Z:、X: 等）。仍然拦截真正的 UNC 路径 `\\server\share`。
- **`~` 开头的工作目录在启动 session 时自动展开**。修掉 "No conversation found" 一类假退出。

## 🔄 模型 / 配置

- **统一升级到 GLM 5.2 (1M ctx)**。glm-5.1 / glm-5-turbo 上游已下线，相关 fallback 切到 glm-4.5-air。
- **MiniMax 默认模型文档同步到 M3**。`providerPresets.json` 早已使用 M3，本次补齐 `.env.example` 与中英文档示例。

## 🧹 清理 & 上游同步

- 删除桌面端 `TextQuestionModal`（启发式抽题弹窗路径不再保留）。
- 同步上游 cc-haha v0.3.1 → v0.4.3 范围内对 AmbiCrew 真正缺失的部分（batch 0/1/5/6），其余批次已独立实现或推迟。
- 跳过 Tauri 时代陈旧的 `updateStore` / `UpdateChecker` 测试（等 Electron 版更新流落地后再启用）。

## 🧪 测试可靠性

- 隔离 `AUTH_MODE` / `ANTHROPIC_DEFAULT_*_NAME` 等环境变量泄露，避免 dev shell 污染测试进程。
- 同步 provider-presets 断言（custom preset 已下线、crewcentral 已追加、MiniMax 默认升 M3）。

---

## 升级注意

- 如果你以前 pin 了 `glm-5.1` 或 `glm-5-turbo` 在自定义 provider 里，请改为 `glm-5.2`，否则会回落到 fallback。
- 如果使用映射盘 + bypass 模式，本版本起开箱可用，无需绕路。
